# Spec 010 D4: the test files whose result can depend on the Node version.
# CI runs the full suite on Node 22 and only these on Node 24
# (`.github/workflows/ci.yml`, job `node24`).
#
# One entry per line, passed to `vitest run` as it is: Vitest keeps a test
# file whose path from the repository root contains an entry (a substring
# match, case-insensitive, not a glob). Lines starting with `#` and blank
# lines are skipped.
#
# `test/version-sensitive.test.ts` fails when an entry matches no test file,
# and when no entry selects:
# - a test file that reads the Node version;
# - a test file that names a node:test project or the node:test adapter, or
#   passes `--test` (`nodeTest`, `NodeTestProject`, `createNodeTestAdapter`,
#   `"--test"`), unless the exemptions below name it;
# - a test file importing, directly or through other helpers, a helper under
#   `test/` that holds a node:test project or passes `--test` itself
#   (`test/scheduler/preload-worktrees.ts`, `test/scheduler/warm-up-repo.ts`,
#   `test/runners/node-test/graph-observed.ts`), unless exempted.
# It also fails when a helper below or a file that imports it is missing from
# this header, or when an exemption names a file the rule does not flag.
#
