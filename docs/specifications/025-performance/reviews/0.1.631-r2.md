`hasFallenUnknownRuns` preflight from `src/core/store/repos/unknown-runs.ts:77`.

preflight in a read transaction and opens a write transaction only when it
finds a fallen record. `dropFallenUnknownRuns` still rechecks under that lock.

The passing real-store tests at `test/daemon/sliced-prune-idle.test.ts:171`
and `:181` exercise both states. A standing UNKNOWN retains its record with
**zero write transactions and zero pauses**. A record at the older revision
is deleted with **one write transaction and one pause**. Prune-once,
keyed-prune and the unchanged key-format gate also passed.
