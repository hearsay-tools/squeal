## The shell block

```sh
if [ "$1" = node ]; then
  if [ -z "${NODE_COMPILE_CACHE+set}" ]; then
    cache=${XDG_CACHE_HOME:-${HOME:+$HOME/.cache}}
    case $cache in
      /*)
        cache=$cache/squeal/compile-cache
        [ -d "$cache" ] || (umask 077 && mkdir -p "$cache") 2>/dev/null || :
        if [ -d "$cache" ] && [ -w "$cache" ]; then
          NODE_COMPILE_CACHE=$cache; SQUEAL_OWN_COMPILE_CACHE=1
          export NODE_COMPILE_CACHE SQUEAL_OWN_COMPILE_CACHE
        fi ;;
    esac
  fi
  # The CLI scripts add: && [ -n "$carry" ]
  if [ -n "${NODE_USE_ENV_PROXY+set}" ]; then
    SQUEAL_CARRIED_NODE_USE_ENV_PROXY=$NODE_USE_ENV_PROXY; export ...; unset NODE_USE_ENV_PROXY
    shift; set -- node --import "<RESTORE>" "$@"
  fi
fi
```

`RESTORE` is `data:text/javascript,if(process.env.SQUEAL_CARRIED_NODE_USE_ENV_PROXY!==undefined){process.env.NODE_USE_ENV_PROXY=process.env.SQUEAL_CARRIED_NODE_USE_ENV_PROXY;Reflect.deleteProperty(process.env,'SQUEAL_CARRIED_NODE_USE_ENV_PROXY')}`. It contains no spaces. It differs from the brief's string in one way: the `if` guard. The CLI passes `process.execArgv` to the runner host and to `relaunch`. Without the guard, a child that inherits that execArgv would set `NODE_USE_ENV_PROXY` to the string `"undefined"`. The coordinator required this guard.

Choices the spec did not settle:

- **Only for `node`.** The hook runners change nothing for another command. Every hook command is `node`.
- **A set but empty `NODE_COMPILE_CACHE` is the user's.** The block tests `${NODE_COMPILE_CACHE+set}`, not `-z`. Node treats an empty value as "off" (probe: `getCompileCacheDir()` gives `undefined`). The Codex adapter does the same with `env.NODE_COMPILE_CACHE !== undefined`.
- **Absolute base only.** A relative `XDG_CACHE_HOME` or `HOME` sets no cache. Otherwise the hook would create `squeal/compile-cache` inside the user's project, which is the hook's working directory. A relative `XDG_CACHE_HOME` does not fall back to `HOME`. The Codex adapter follows the same rule.
- **Export only a writable directory.** Node quietly ignores an unwritable cache directory (probe: exit 0, `getCompileCacheDir()` gives `undefined`). The block still exports nothing in that case, so children see no useless variable. Each test is a shell builtin. `mkdir` runs once per machine.
- **The Codex adapter marks `env`.** `enableCompileCache` does not set `NODE_COMPILE_CACHE` for children (probe). After status `ENABLED` or `ALREADY_ENABLED`, the adapter sets `env.NODE_COMPILE_CACHE` and `SQUEAL_OWN_COMPILE_CACHE=1`. A daemon that a Codex hook starts then gets the cache too, and the runners strip it, as on the shell paths.

## Coordinator decisions

1. **Carrying the switch breaks `fetch` in the CLI process.** Probe on Node 26.13, with `HTTP_PROXY` pointing at a local proxy. `node -e 'fetch(...)'` with `NODE_USE_ENV_PROXY=1` goes through the proxy. The same command with the switch carried and restored by the preload goes direct (`ENOTFOUND`). Node sets the proxy up only when it starts. `squeal update` and `squeal codex-runtime` call the global `fetch` in the CLI process (`src/harness/codex/runtime-release/transport.ts`). Decision: the CLI launchers carry the switch only when the first argument is one of `status|why|failures|checks|ps|start|stop|run|retry|hold|lint|code|impact|reach|--version|-v|--help|-h|help`. Every other command keeps the proxy setup: `update`, `codex-runtime`, `remote`, `remote-tunnel`, `daemon`, `runner-host` and unknown commands. Hooks always carry. `why` is not a CLI command today; it stays in the list and does no harm.
2. **`test/keys/launchers.test.ts` amendment approved.** See the table above.
3. **Validity cases approved (option A).** `test/keys/key-format.test.ts` failed with "changed lines no case runs" for `VITEST_ADAPTER_VERSION`, `NODE_TEST_ADAPTER_VERSION` and `PYTEST_ADAPTER_VERSION` at `src/core/env/compile-cache.ts:27,28,38,39`. Those lines are the strip branches. With the `ownCompileCache` cases it passes, and `KEY_FORMAT_VERSION` is unchanged. The empty `NODE_COMPILE_CACHE` keeps Node's cache off in the driver's children, so V8 coverage reads the same at both sides.
