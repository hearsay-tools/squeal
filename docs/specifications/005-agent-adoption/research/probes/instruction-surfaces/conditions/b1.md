## Tests and Squeal

This repository uses Squeal: it runs the Vitest tests in the background after each edit and reports changes in SQUEAL messages. Wait for it instead of running Vitest: `squeal status --wait 60000` (the SQUEAL messages name the command if `squeal` is not on your PATH). Run the full suite yourself only as a final gate when the cost is justified. If no SQUEAL message has appeared in this session, Squeal is not running here: run the tests yourself.
