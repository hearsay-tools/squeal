Locations: `src/core/retry/advice.ts:49` and `src/core/delivery/format.ts:611`. The existing `assemble` at `format.ts:273` reserves the complete footer before fitting blocks. This wave introduces an unbounded list of up to five paths into that footer.

Contract: 005 D6 says “Every text change keeps the 10,000-character cap”. Row 005-92 requires “block order, grouping, overflow counts and the `Full output:` line unchanged”. The brief also requires that no failure facts disappear when lines merge.

Failure scenario: a registration contains five recorded failures, each in a different deeply nested test file. All ran at load 2 per CPU and have no retry. A path can be 2,362 characters with every component only 180 characters; these paths fit Linux path and component limits. `FILES_NAMED` limits the count, but not the total characters. The advice alone exceeds the message budget. `assemble` then gets a negative `room` and appends the whole oversized footer after cutting away the header and overflow summary.
