## Blockers

### B1. Proven: the suggested pytest exclusion can remove tests that only the outer project runs

Location: `src/cli/setup/runners.ts:117-123`, especially line 123. Row 005-80, 005 D3 step 2, and the review brief require a fix for each overlap. The brief explicitly says that the suggested `exclude` must remove exactly the shared files from the outer project.

`overlapFix` uses only the two project directories. When one directory is inside the other, it tells the user to exclude the whole nested directory. The nested project's `include` and `exclude` can select fewer files than the outer project selects in that directory. Following the printed fix then leaves some tests with no project that runs them.

Reproduction at the candidate, in a scratch Git repository with these tracked files:

```text
tests/test_root.py
plugin-tools/a/tests/unit/test_shared.py
plugin-tools/a/tests/integration/test_outer_only.py
```

Use this configuration:

```json
{
  "nodeTest": [],
  "pytest": [
    { "name": "outer", "include": ["**/test_*.py"] },
    {
      "name": "unit",
      "cwd": "plugin-tools/a",
      "include": ["tests/unit/**/test_*.py"]
    }
  ]
}
```

Run the built CLI with `setup --plan --json`, then add its suggested exclusion to `outer` and run the plan again. The output is:

```text
before.overlaps = [{"projects":["outer","unit"],"testFiles":1,"fix":"add \"plugin-tools/a/**\" to the exclude of pytest project \"outer\""}]
before.warmup = {"source":"default","testFiles":4,"paths":3,"withoutCurrentResult":4}
after.warmup = {"source":"default","testFiles":2,"paths":2,"withoutCurrentResult":2}
after.overlaps = []
expected remaining runs = 3; actual = 2
```

An independent call to the actual pytest adapter's `listTestFiles` confirms the coverage loss. This does not rely on the plan's own estimate:

```text
outer ["plugin-tools/a/tests/integration/test_outer_only.py","plugin-tools/a/tests/unit/test_shared.py","tests/test_root.py"]
unit ["plugin-tools/a/tests/unit/test_shared.py"]
after suggested exclusion
outer ["tests/test_root.py"]
unit ["plugin-tools/a/tests/unit/test_shared.py"]
```

Worker-sized fix: pass the shared file set and the outer selection to `overlapFix`. Suggest a directory exclusion only when it removes exactly that shared set from the outer selection. Otherwise name only the shared files, or use the existing generic instruction to narrow one project's selection. Keep paths relative to that project's `cwd`.

Add tests for nested projects with a narrower inner `include` and with an inner `exclude`. Apply the suggested fix and assert that the union of test paths stays unchanged while each shared file runs once. The current tests assert the suggested text but do not apply it to a case with an outer-only test under the nested directory.
