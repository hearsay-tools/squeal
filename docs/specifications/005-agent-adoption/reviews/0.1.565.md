## B1 — the lint inventory does not follow enabled tools and ownership

**Proven, blocking.** `src/cli/checks-text.ts:153` and `:57`.

Spec 019 D2: “With a `checks` key, these defaults hold only for the checks no group owns.” D6's new command is “the one place that lists this repository's checks”, including when each runs. The brief specifically requires correct output for a lint check.

Valid config:

```json
{
  "lint": { "enabled": true, "tools": ["eslint", "oxlint"] },
  "checks": [{ "name": "style", "lint": ["eslint"], "at": "manual" }]
}
```

A scratch probe invoked the real `readPolicy`, `resolveGroups`, `groupOf` and CLI `main(["checks"])` against this config, without a daemon or store. The resolver returned:

```text
eslint: owner style, moment manual
oxlint: no group, default moment edit
```

The CLI printed `style`, selecting ESLint and running only on request, followed by `tests`. It printed no Oxlint block or name. `defaultLintBlock` returns `null` merely because one lint group exists. The actual lint pass keeps unowned Oxlint at its default moment: `src/core/lint/pass/moment.ts:34` returns no hold when no group owns a tool. Thus an agent learning the checks from this command cannot discover a check that Squeal runs after edits.

The reverse case also fails. With only `{"checks":[{"name":"style","lint":["eslint"],"at":"edit"}]}`, lint is disabled by default. The same probe confirmed `readPolicy(root).lint.enabled === false`, yet the command printed `style` with `Runs: after each edit`. `checksText` renders every configured group without checking whether lint is enabled. The actual pass returns without linting under that condition (`src/core/lint/pass/index.ts:108`). No line told the agent that this declared check will not run.

**One-worker fix:** derive the effective lint inventory from enabled tools and the existing ownership rule. Print the default lint block for unowned tools only. Suppress it only when none remain. Omit disabled lint groups from the active list, or mark them explicitly disabled instead of claiming they run. Add CLI regressions for partial ownership, all tools owned and lint disabled with a declared group. Keep `checks` read-only and the approved skill/start-message texts unchanged.
