## Stop repair and ownership

`src/cli/stop-at.ts:65` saves the validated marker and lock path before sending stop. It can therefore wait for the claimed daemon after that daemon removes `.git` and the marker no longer identifies a complete worktree. The committed race test passes with this code and fails with the old source, as recorded above.

The temporary probes used a real commit-worktree fixture, socket replies, live child process leases and a held SQLite daemon lock:

| Unclaimed daemon keeps its lock, with another live process recorded as creator | Exit 1 after 399 ms; tree and live owner retained. Removal still applies the owner guard after the bounded wait. |
