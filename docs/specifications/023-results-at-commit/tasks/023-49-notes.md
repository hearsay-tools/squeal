## Decisions the spec did not settle

- **The estimate moved from stderr into the report.** It now speaks of what still runs after the wait, which the call knows only then; one place, also in JSON. `tellsEstimate` is gone: the line shows whenever something still runs.
- **Measured rate over stored durations.** Round 6's own numbers (90 to 157 results in 320 to 400 s) are this call's rate; it already holds the pool's share and the load. Its time includes the commit daemon's install and keying, so it errs long, never short.
- **Pool share, not slots.** A side's width is its `fairShares` share of `capacity.hostSlots`, as the pool divides it for backlog demand, with this call's two sides replacing their own marks. The background ceiling (021 D18) is not applied: narrow runs are named waits, outside it.
- **Narrowed `--wait` waits for its own files only.** Before, it waited for every kept ask's files (round 6: 1,338) up to its bound.

Decisions the review did not settle:

- **A named source folder selects no reader.** The commit ask's `choose()` reads readers of a path exactly (`reverse.referencing`), and the working tree's named wait selects only the test files under a folder (row 011-406, gh-169). The join keeps that rule: a source folder narrows to the test files under it, so it joins and waits for nothing of an unrelated queue.
- **The readers come from the daemon's `sync`.** It is the daemon's existing read-only query for a named wait's readers (row 011-234). It is not asked while the commit daemon sets up: its sync would wait for the start, and it has queued nothing then.
- **A shared `maxParallel` slot counts both sides' work.** A side's group time is at least both sides' files of the group over the slot, so the estimate errs long when the other side's files run first, as the rest of this estimate does. Other worktrees on the same slot are not seen.
- **`--wait`'s change identity is computed again** with the same git reads `--run` sends (`git diff <commit> HEAD`, then staged, unstaged and untracked paths). A failed read leaves it unknown.
