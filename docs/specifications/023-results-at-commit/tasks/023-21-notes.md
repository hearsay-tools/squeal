## Decisions the brief did not settle

- **Source roots.** Squeal knows no project's source roots (`core/reach/names.ts` says so too). A changed code-side import is a `--with` candidate when `isHelperPath` takes it for a helper by folder (`testing`, `test-utils`, `test-helpers`, `testkit`, `mocks`, `e2e`, and the test folders) or name (`*.testkit.*`, `*.test-utils.*`, `*.test-helpers.*`, `*.fixture(s).*`, `*.mock(s).*`, `test-*.*`). Every other one is source. Test-side changes (`isTestSide`, named and `--with` paths included) are copied already and are neither.
- **Only source changed.** An unchanged test whose closure changed only in source files still runs: this is the ordinary "commit the failing test, then the fix" proof. Stopping it would loop, since its rerun would add no `--with`. It is not silent: the note line names what was compared as source, so a helper with an unconventional name (`src/rowsKit.ts`) is visible and can be given with `--with`.
- **The stop needs no source change.** A changed helper alone stops the file; with `--with` the default case becomes `test` (only test-side paths changed), so a helper-only fix proves as a test case.
- **The rerun line** is the call's own command plus the helpers as paths from the cwd, `--with` paths already given kept first; `--timeout` only when it is not the default. Helpers from every stopped file go in one line.
- **The warning** uses the closures at `HEAD` from the green checkout; with no named file keyed there, no warning is given (nothing is known).
- **JSON sides** always carry `with` (an empty list without `--with`). Added fields only; `squeal-proof/1` stays.
- **`--with` of a named file** is dropped (it is named already); a path given twice counts once.
