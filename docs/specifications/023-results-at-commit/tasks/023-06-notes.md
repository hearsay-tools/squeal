## Flow

1. `locate`: the worktree root from the real cwd, `resolveCommit`, paths made root-relative (outside the root: exit 2).
2. `nowSide`, store open read-only (`withStores`):
   - a daemon whose heartbeat is fresh (`worktreeLiveness`): its `test_file_keys` rows and the results at those keys; no keying. Revision: the highest row revision. A row with key `null` is `not determined (the daemon has no key for it)`; no result with `pending` reads `no result (queued|running)`. The states are read before the store closes.
   - no daemon: `withKeyer` in the worktree (the same keyer and policy reading as `keysAtCommit` in the checkout, so keys compare), results at its keys. Not `storedFiles` (020 D11.7's entry): that one returns `null` with coverage off and forces `coverage.children`, which would give keys other than the commit side's. Only results are read, not coverage records.
3. `keysAtCommit` with the selected files (all files at the commit when no path is given), the CLI's `daemonAdapters`.
4. With no paths, the files are the union of both listings: a file only at the commit reads `absent` now (or `not determined (no runner lists it)` when the file is on disk); a file only now reads `absent` at the commit.

## Decisions the spec did not settle

- A path that selects no test file now is asked at the commit as a file of the default project (`project: ""`); a folder that holds test files only at the commit is not expanded.
- Origin: a record's `origin: "ci"` field (023-17's mark, parent's reply 2026-11-17) first, then the provenance worktree: own, `import:` mark, or another worktree. The newest record names the origin.
- Fail when any record at the key failed; otherwise pass (skip-only counts as pass).
- `pending` belongs to `no result`, not `not determined`.
- `--run` is refused with a usage error until 023-07; `--at` takes no other status option (`--wait`, `--check`, `--full`).
- Text mode writes one stderr line before the checkout (`keying test files at <sha> in a temporary checkout`); JSON mode writes none.
- The 7-day line: more than half the files `no result` at the commit and the commit's committer time more than 7 days before now.
