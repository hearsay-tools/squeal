## Decisions the brief did not settle

- **Exit code with `red without them too`.** The verdict stays `proven` and the exit stays 0: under the conditions, red failed and green passed. The verdict's reason says the conditions are not shown to matter. A new verdict or exit code would change D5.6; the brief says only "the verdict says".
- **Which files get a control run.** Only files whose red side failed on assertions alone: the only verdict (`proven`) the control can qualify. For the others the line says why it did not run, in the same words as the green side.
- **A budget-cut control run** counts in `notRun` and brings the rerun line; the verdict does not change.
- **The control run sees the real `HOME` and environment**, as any unconditioned run does. `proof-review9`'s B1 probe test wrote into its `HOME`; its probe now only reads when `HOME` is the command's own (`PROOF_REAL_HOME`).
- `proof.ts` grew past 300 lines; the files and counts moved to `src/cli/proof-files.ts` (`provedFiles`, `endOf`).
