## Decisions (parent's reply, 2026-11-19)

- **HEAD with `--run` runs as before.** `status --at HEAD --run --all-missing` fills HEAD's results in a checkout without a daemon; the e2e (`test/e2e/at-commit-status.test.ts`, step 2) and the review-13 fixture tests use it.
- **HEAD with a dirty tree compares as before**: it answers "did my uncommitted edits change results". Only a clean tree is refused. Clean is `readHead`'s `dirty` flag, the same the report's header shows: `git status --porcelain --untracked-files=normal`, so tracked changes and untracked files make the tree dirty; ignored files do not. An untracked file can change a key (a new test, or a source a test imports), so it counts.
