Layout: `<dir>/<id>/marker.json`, `<dir>/<id>/tree/` (the worktree), `<dir>/<id>/run/` (the run's `TMPDIR`). `<dir>` is `<cache>/squeal/checkouts/<sha256(commonDir)[0:16]>` or `<common dir>/squeal/checkouts`. The marker lies beside the tree so the tree stays clean. It is written under the lock before `git worktree add`; a folder with no marker that the sweep finds under the lock is a half-made create and is removed.

Lock: `<common dir>/squeal/checkouts.lock`, a SQLite exclusive lock (`awaitDaemonLock`), 60 s wait. Create, remove and sweep hold it.

Owner identity: `leaseProcess()` (pid, `/proc` start time, PID namespace); `ownerState` uses `leaseProcessAlive`. Another PID namespace reads `unknown` and is not swept.

## Pass `commonDir` as a realpath

`sweepCheckouts` skips a marker whose `commonDir` differs from its own, and `ps --repo` compares them as strings. `resolveCommonDir` returns a realpath; use it.
