## Flow

1. `atRun` starts the budget clock before `commitSide`, so the sweep, checkout, install and keying count (D4.6).
2. In the checkout, after keying: the files with a key and no stored result. D4.9: a file whose `loads` holds a path git does not hold at the commit **and** that exists in the checkout reads `not comparable (needs <path>)`. A path absent from the checkout too (a snapshot file Vitest lists as a possible input) is not a reason: the run sees it absent, as at the commit. The first probe without the existence check refused every file for its `__snapshots__/<name>.snap`.
3. Selection (D4.5): without `--all-missing`, a file whose own path or one of its `loads` is in `git diff --name-only --no-renames <commit> HEAD`. With `--all-missing`, every file with no result, after the estimate line (`estimateRun` over `storedDurations`, Vitest's width).
4. `runGateFiles({ root: checkout.tree, files, budgetSeconds: left, env, tempDir: checkout.run })`. Under 1 s left: nothing starts, every selected file reads `not run (budget)`. `not-finished` maps to `not run (budget)` too.
5. The gate keeps completed files in the shared stores (020 D17.3) only when coverage is on (`storedFiles` returns `null` otherwise): the keys are the same as the keyer's because the checkout's base policy is its own committed policy. The tests use a config with coverage on; with coverage off, `--run` runs and reports but stores nothing.

## Decisions the spec did not settle

- A `--run` result's origin is `run` ("run by this command"), also in the rare case the gate read the file from the stores (another writer between keying and run).
- A file started and stopped by the budget reads `not run (budget)`, like one never started.
- The rerun's `--timeout`: what was spent before the gate plus twice the left files' estimate, rounded up to a minute, at least 60 s; with no stored duration, twice the given `--timeout`, rounded the same way.
- The estimate line goes to stderr in text and JSON mode, and into JSON `run.estimate`; the gate's own notes go to stderr in text mode only.
- `--all-missing` and `--timeout` without `--run` are usage errors.
- A failed checkout prints no `--run:` line; the failure line says why.
