# Row 023-26 notes: the named wait while the daemon starts (Q7)

## What changed

- `src/cli/named-listing.ts` (new): `listingOf` reads whether the listing is done, the same way the header does. It returns `{ revision: null }` when the daemon has not listed this worktree's test files: no key rows, and no completed full pass or an install awaited (`testFilesListed`). It returns `{ revision: n }` when revision n's runner part is not applied (`runnerPartPending`). `withUnlisted` adds the time so far and `partial`. `unlistedText` gives the words.
- `selectNamedFiles` sets `NamedSelection.unlisted` when a path selects nothing and the listing is not done. Such a path gets no prefix hint (`startsWith`) and no `fromRoot`, because both read the listing.
- `unmatchedText` returns only `unlistedText` when `unlisted` is set. This covers the closure text, the folder text and the prefix hint.
- `namedPoll`: when `selection.unlisted` is set, no read decides. Before this row, a synced daemon with nothing listed ended the wait as `unmatched` at the first read, and the promotion and the asked runs happened with no files. At the end, `withUnlisted` sets `partial` (row 011-401: `complete: false`). When a daemon holds the worktree, it also sets `forMs`: the time since the daemon's `startedAt`, or since the revision was recorded, and never less than the wait's own time.

## Texts

- A wait with a daemon: `Squeal is still starting here (62 s); wait again with the same command`, or `Squeal has not listed revision 5 here yet (3 s); wait again with the same command`.
- No daemon (the `no-daemon` outcome), or a snapshot: `Squeal has not listed the test files here yet` (or `revision n`). Here no daemon may be starting, so the text does not say "starting".

## Not done (outside this row's three files)

Worktree: …; the daemon has not listed this worktree's test files yet. … For the verdict, wait again: \`squeal status --wait 60000 …\``. The `Selected:` line also prints with no files. To make the line say only the starting text, a later row would change `namedLine` (the `timeout` case) and `selectedLine` to read `selection.unlisted`.
