- **Conditions (D5.3).** `--env NAME=` unsets `NAME`; `--env NAME=value` sets it. `--without <path>` hides a file or folder from the run. A path under `HOME` is hidden by giving the run its own `HOME` that holds everything else the test reads there; a path inside the repository is hidden in the checkout (and counted in the expected tree, so the whole-checkout check still holds); any other path outside `HOME` and the repository is a usage error (exit 2) with one line saying why. The same conditions apply to both sides. A side under any condition always runs, is never read from the store and is never written to it (`store: false`); the report names the conditions.
- **`--case dependency`.** Red = the test at `--base`, green = the test at `HEAD`, both over the code at `HEAD`, both under the conditions; at least one `--env` or `--without` is required (exit 2 without). The default case rules of 023-08 stay; `dependency` is chosen only by `--case`.
- **Repeat (D5.4).** `--repeat <n>` (integer, 1 to 100; else exit 2): the red side runs up to n times and stops at the first failure; the green side runs n times and must pass every time. A `test` red side with `--repeat` above 1 runs even when a stored result exists (D5.1). Per-project evidence as 023-08 reads it, per run; the verdict uses the first failing run's evidence; the report carries the run count per side.
- **Budget.** The one `--timeout` covers every run of both sides; runs not started read `not run (budget)` with 023-07's rerun line, and the verdict for that file is `not comparable (budget)`.
