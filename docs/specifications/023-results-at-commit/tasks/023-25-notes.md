## Probes (`023-25/bin/`)

Throwaway, not product code. Each takes the Squeal folder whose `dist/` it imports.

- `probe.mjs <squeal> <worktree> <commit> <project> <path> <out.json>`: one file's key inputs in the worktree and in a checkout at the commit, and their differences.
- `keys.mjs <store.sqlite> <path>`: the daemon's key for the file and the keys its results are stored at.
- `deps.mjs <squeal> <tree>...`: the installed-dependency reading (fingerprint, graph or none, note).
- `meta.mjs <store.sqlite> <path>`: the store's meta keys, and the file's entry in the observed maps.

On the VM: non-interactive ssh does not load nvm (`bash -lc`); a run that must outlive the ssh call needs `setsid nohup` inside `bash -lc`, or `node` is not found.
