## Decisions the brief did not settle

- **Wording.** The brief's text is "without this commit's changes to it". With `--at HEAD~3` or a dirty tree the changes are not one commit's, and "this commit" can be read as `a5c9b7223` itself. The line says "without its changes since then" (`asItWasText`). One word to change if the coordinator wants the brief's text.
- **Which sides.** Only a pass or fail at the commit is marked: a file with no result has no run to misread. The working tree side is not marked.
- **Which calls.** The commit side of `--run` and `--wait` (`rowsSide`). The call without `--run` reads the commit side through `status-at-commit.ts` (no worker's file in this wave); it is not marked. Round 9's misreads were all in `--run` calls.
