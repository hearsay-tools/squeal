Row 023-79, wave 36, worker B, 2026-11-24. Brief: `wave-36.md`, "Worker B". Base 0.1.611.

## Change

- **State.** `GroupTierState.pendingOutside` (new, optional, `src/core/types/status.ts`): at `manual`, the paths of the group's pending files that no narrow request asked for at their current key, when 1 to 3 are. `requestedOf` in `src/core/state/groups.ts` now returns both the count a request queued and the others. With no live daemon or no published asks, every pending file is outside a request.
- **Text.** `src/core/state/group-text.ts`: `96 queued by a request (…), 1 pending (packages/web/e2e/activity.e2e.ts), waiting for \`squeal run browser\``. The paths are printed only when their count equals the pending count less the requested count, so the line never names a different set than it counts. Four or more are counted only. Status and the hooks use the same `groupTierText`, so both name them.

## Decisions the brief did not settle

- **`manual` only.** The brief says "a request-only group". A `commit` group's files wait for a commit, which the agent makes anyway, so its line stays as it was (`1 pending, waiting for a commit`).
- **Full relative paths**, as the other lines name files. Base names could be ambiguous across folders.
- **The evals parser** (`evals/lib/squeal-text.mjs`, `waitingOf`) keys on "waiting for \`… run <group>\`", which the new text keeps. The tests check it on the hook's JSON.
