# 021-15: the team test host (an LXC container on the 3900X host)

What the container needs so Squeal's remote runner can use it for row 021-15 (proof on a real second machine). The human's IaC agent sets it up; the coordinator then writes `remote.json` on the agent host and runs the trial.

## Machine

- Debian 12 or Ubuntu 24.04, an unprivileged LXC container is fine. No nesting and no Docker are needed.
- 8 vCPUs (of the 3900X's 24 threads), 16 GB RAM, 40 GB disk on SSD.
- Time kept by NTP.

## Network

- SSH (port 22, or another port you tell us) reachable from the agent host.
- Outbound HTTPS to `registry.npmjs.org`, `github.com` and `objects.githubusercontent.com`, so the container can install the project's packages from its lockfile.
- No inbound port other than SSH.

## Login

- One non-root user, `squeal`, with a home directory, `bash` as its login shell, and no sudo.
- Key login only (no password). Add this public key to `/home/squeal/.ssh/authorized_keys`:

  ```
  ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIDSb3r3zfrh1ixfV97WjDmRqvgrTe5NJr7C2vhqin+qk squeal-021-15-trial@agent-host
  ```

  It is a key made only for this trial, kept outside the agent's own `~/.ssh`.
- Send back: the host name or IP, the port, and the SSH host key fingerprint (`ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`), so the first connection is checked, not trusted blindly.

## Software, for the `squeal` user

- **Node 26.13.0 exactly.** Squeal accepts a remote result only when the remote's Node version equals the local daemon's, and this host's daemons run Node 26.13.0. Installing it with `nvm` (as the `squeal` user) makes a later version change one command; put it first on the `PATH` that a non-interactive `ssh squeal@host <command>` sees (for nvm, set it in `~/.bashrc` above any "return if not interactive" line, or link `node` into `~/.local/bin` and put that on the `PATH` in `~/.profile` and `~/.bashrc`).
- `corepack enable` for that Node, so the project's pinned `pnpm@12.15.0` is used.
- `git`, `tar`, `gzip`, `coreutils`, `sh`/`bash`.
- `build-essential` and `python3`, in case a dependency builds a native module.
- Not needed for this trial: Python test tooling, browsers, Docker.

## Disk use by Squeal

Squeal keeps everything under the `squeal` user's cache (`~/.cache/squeal/` by default): its own bundle per version (about 10 MB), one copy of each worktree's tracked and non-ignored files (this repository is about 200 MB without `node_modules`) and its `node_modules` (about 650 MB). Ignored files such as `.env` and the `.git` folder are never sent.

## Nothing else

Squeal installs itself on first connect over SSH and checks a checksum; it needs no global install, no service and no open port beyond SSH.
