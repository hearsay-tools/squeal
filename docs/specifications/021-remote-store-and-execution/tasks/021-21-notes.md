## Flow of one background run on a remote

1. Selection takes the local grant as before (the local ceiling and floor apply).
2. `executeTier` passes `permits` (a `TierPermits`).
3. The lane sends pending files, compares the environment (refusal here keeps the local grant: the run goes here at once).
4. `admitRun`: `permits.away()` releases the local grant; then `admit` every 2 s (`ADMIT_EVERY_MS`, as `CAPACITY_RECHECK_MS`), each one non-blocking `acquire` of kind `backlog` on the remote pool, asking the tier's width and its fewest workers (`tierWidth`, as `widest`/`fewest` in `tiers.ts`). Each ceiling refusal goes to the daemon log: `remote box: on its machine, the background ceiling refused a backlog tier: 20 busy CPUs, ceiling 18 (0.75 of 24 CPUs)`.
5. Granted: the run goes with `workers` = the remote grant and `admitted: true`; the host claims the held grant and returns it when the run ends.
6. Back here (tree refused twice, host lost, `whenLost: "local"`): `permits.back()` waits for local permits as a backlog tier does; the run goes at the grant it gets.

## Decisions the spec did not settle

- **One look per request; the lane polls.** The run's deadline (`timeoutMs + runMarginMs` on a remote) starts at its request, so admission inside `run` would time a long wait out. A separate request needs no change to `proxy.ts`. A cancel ends the wait at once.
- **A cancel during the wait** returns `completed` with no file (`notStarted`), so `storeDecision` queues the files again (a `crashed` report of a cancelled tier makes them `unknown`). A grant that arrives with the cancel goes back with `admit` of 0 workers.
- **A grant waits 30 s for its run** (`ADMITTED_HOLD_MS`), then goes back; a new look returns an unclaimed one first.
- **A look that stops** stays a waiter in the remote pool until the pool forgets it (30 s), as a local daemon's does. It holds no permit; it keeps its place for the next tier.
- **Fallback kind**: `back()` asks as `backlog` (under the ceiling) also for a checkpoint tier's run; executeTier has no ledger to tell.
- **A failed remote pool** (directory refused) admits the run without a grant and the lane logs why, as `TierCapacity.take` runs a tier ungranted.
- **A host without admission** (a local host, tests' in-process hosts) answers every `admit` with the full ask.
