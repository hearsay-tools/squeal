## 021-11 the runner host, and Vitest as a local child host (shape: slice)

Outcome: `squeal runner-host <root> --runner vitest` hosts the project's Vitest adapter in its own process, and the daemon drives it through a proxy adapter. Read spec D6 to D8, `research/runner-split.md` Q1 to Q3 and Q6, `research/daemon-model.md` Q3, and the throwaway prototype `research/probes/runner-split/host.mts` and `driver.mjs`. Seam: `src/core/daemon/daemon.ts`, about lines 560 to 640, where each Vitest instance is built by `createRecoveringRunner({ create: vitestInstance(...) })`; first edit: a `create` that returns a proxy `RunnerAdapter` over a child's stdio. New module `src/core/runner-host/` (protocol, host, proxy) and the CLI command (`src/cli/runner-host.ts`, registered in `src/cli/main.ts`). Owns those, the create site in `daemon.ts`, and their tests. Leaves the rest of `daemon.ts` (021-08). The host's cwd is the root; its stdout carries only marked protocol lines; input end stops its run and workers; every request has a deadline; a host that exits or misses one makes the run incomplete and the recovering runner starts another. No SSH, no blob proof yet (021-13, 021-14). Done when: the existing Vitest runner tests pass through the proxy with the same results as in-process; a killed host ends its tier `unknown` and is replaced; `squeal ps` shows the host under its daemon. Use /worker.
