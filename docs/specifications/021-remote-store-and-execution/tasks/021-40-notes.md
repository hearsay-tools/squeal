# 021-40: test files that always run here (`remote.runHere`, #294)

Shape: slice. Use /worker.

Outcome: a project lists test files that read this machine's own kernel, processes or tools in `remote.runHere`; while a remote lane is on, those files always run here, also when the remote tree is a Git repository, so a host-dependent remote failure never replaces a local result under a shared key ([#294](https://github.com/hearsay-tools/squeal/issues/294)).

Read: spec 021 D19 (the two settings and the guard), 026 D8.3 (remote planning) and D8.4 (`needsRepository` goes remote when the machine has `.git`). `runHere` differs from `needsRepository`: no condition, it never goes remote.

Seams and first edits:

1. `src/core/types/policy.ts`: `remote.runHere: readonly string[]` beside `needsRepository`, default `[]`, its own docs comment.
2. `src/core/daemon/policy-remote.ts`: `runHere` validated as globs, as `needsRepository` is.
3. `src/core/runner-host/remote/lane-repository.ts` `repositoryRoute`: a file matching `runHere` stays here regardless of `remoteHasRepository`. Then thread the option through `lane.ts` and `daemon-lane.ts` as `needsRepository` is threaded. Check the remote-planning path (`planning: "remote"`) routes the same way.
4. The policy reference doc that the four `plugins/*/skills/squeal/references/policy.md` copies come from: one line for `remote.runHere`. Find the source and its sync step; do not edit the copies by hand if a generator exists.
5. `squeal.config.json`: add `test/ps/proc-live.test.ts` to `remote.runHere`.

Owns: those files and their tests (`test/runner-host/remote/lane-needs.test.ts`, `policy.test.ts`, `test/types.test.ts` as needed). Leave `src/core/ps/*` and `test/ps/*` alone (the coordinator's commit 014-50 already changed them). Do not touch keys, validity code or the board. Do not run `pnpm run build`.

Done when: tests show (a) a `runHere` file never goes remote, with and without `hasGitRepository`, in both local and remote planning; (b) an invalid glob is refused with the key named; (c) the default is `[]` and changes no routing. `squeal status --wait 60000 <changed paths>` read; lint and `pnpm run typecheck` clean.
