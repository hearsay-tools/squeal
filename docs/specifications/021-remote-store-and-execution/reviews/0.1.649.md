## Blockers

### B1. Proven: relative file-bound listeners still report an empty readable set

Location: `src/core/ps/proc.ts:182`. Contract: `src/core/ps/source.ts:143`, and the review brief's requirement to return `null` when fallback file-bound listener lines lack `ino:`.

The new branch identifies a filesystem socket only when its printed name starts with `/`. Linux permits binding a relative name. Real `ss -xle` preserves that relative name. With `unix_diag` unavailable, that listener is skipped and the method returns `[]`. This still claims a readable empty set when file inodes cannot be read.

The probe bound real UNIX listeners, then ran the host's real `ss` twice. In the second child process only, an `LD_PRELOAD` socket wrapper refused `AF_NETLINK` protocol 4 with `EPROTONOSUPPORT`. This forces ss's own `/proc/net/unix` fallback without changing the kernel or other processes. The same relative listener produced:

```text
# Normal ss output:
u_str LISTEN 0 1 relative.sock 22684554 * 0 <-> ino:1075846326 dev:0/66306 peers:
# Fallback ss output:
u_str LISTEN 0 0 relative.sock 22684554 * 0
```

Queue alignment spaces are collapsed above. Passing the actual fallback line to `createProcSource({ run: () => line }).unixListeners()` returned `[]`; the assertion expecting `null` failed. The normal line returned its file inode. The counterexample therefore does not depend on an invented ss format.

A minimal reproduction from the candidate is:

```sh
pnpm exec tsx --eval 'import { createProcSource } from "./src/core/ps/proc.ts"; console.log(createProcSource({ run: () => "u_str LISTEN 0 0 relative.sock 22684554 * 0" }).unixListeners())'
# Actual: []
# Required: null
```

Consequence: `discover.ts:330` converts this `[]` to `listening: false` for socket files, instead of preserving an unreadable state as `null`. A host containing only relative and abstract listeners exposes this case; another absolute listener must not be required to detect the fallback.

One-worker fix: classify a bound filesystem name without requiring an absolute path. Preserve the exclusions for abstract `@` names and unbound `*` names. Add a regression for a relative name without `ino:`, including a name with spaces and a negative socket inode. Keep the normal relative-name case with `ino:` as a control. Rebuild bundles after the source repair in the candidate's normal integration step.
