# 001-135 notes: the recorder's reach repairs

Seam map for whoever touches the recorder next (`reviews/wave-12d.md` B2, B3, B4, B6).

- `src/runners/observe/recorder.cjs`: settings, attribution (`current()`: Vitest state, then `settings.file`, then a thread's environment data), `scoped`, the batched writer, `record(kind, p, real)`. `record` adds the realpath of every newly seen kept path when it differs and is kept too (B2); the resolve hook passes `real = true`, since Node already resolved through links. The worktree's own realpath is mapped back to `root`, so a symlinked worktree does not double every path.
- `src/runners/observe/fs.cjs`: every `fs` and `fs.promises` wrapper. Opens are classified by Node's flag table (`FLAGS`, mirroring `stringToFlags`): readable access mode records `f`; `O_TRUNC`, or `O_CREAT` on an absent path (one `lstat`), records `w` (B3). Descriptors and `FileHandle`s opened on a kept path are tracked (`fds`, `handles`); `write`, `writev`, `ftruncate` (sync and callback) and the `FileHandle` prototype's `write`, `writev`, `writeFile`, `appendFile`, `truncate`, `createWriteStream` record `w` for the tracked path. The `FileHandle` prototype is wrapped on the first promise `open`, before the caller's own `then` runs.
- `src/runners/observe/spawn.cjs`: env injection. `optionsAt` mirrors `normalizeSpawnArguments`, `normalizeExecFileArgs` and `normalizeExecArgs` (Node 24.21 sources): any call Node rejects, or whose `env` is truthy and not an object, is passed through with its original arguments (B6). Options are copied with their prototype and descriptors (`withEnv`), so Node reads the same values; a spawn env is copied with `for…in` (Node includes prototype keys), a Worker env with its own keys (Node uses `ObjectEntries`). The Worker constructor sets environment data `squeal.observe.file` before `super()`; Node snapshots it at construction, and it is readable in the thread's preload (B4).
- The build copies every `.cjs` under `src/runners/observe/` into `dist/observe/`, so the split needed no build change; `test/harness/codex/plugin.test.ts` pins that list.

Limits kept explicit (D4): a symlink target outside the worktree; a `SHARE_ENV` thread whose shared env no longer carries the recorder's `NODE_OPTIONS`; a call with a truthy non-object env; `execFileSync(file, callback)`; a descriptor opened outside the wrappers (an inherited fd) written through.
