## Blockers

### B1. Proven: command-only execution fails noisily when the plugin root contains spaces

Location: `plugins/claude-code/hooks/hooks.json:9`, repeated in all 12 entries; test coverage at `test/harness/dropped-args.test.ts:17` and `:43` fixes the root to the space-free repository path.

CC1, amended 2026-10-20: "every entry's `command`, run on its own with a hook payload on stdin, runs nothing, reads none of its stdin as code, and exits 0 with no output." The command is an unquoted shell expansion. A plugin imported from a directory containing spaces is a concrete exception, even with a valid executable launcher. Both hook transports have the same word splitting.

Reproduction: copy the tracked candidate plugin to a directory named `plugin with spaces`, retaining its executable mode, set `CLAUDE_PLUGIN_ROOT` to that directory, and run the manifest's command unchanged:

```sh
CLAUDE_PLUGIN_ROOT='/tmp/sq-012-01-contract-1rPb0P/plugin with spaces' \
  sh -c '${CLAUDE_PLUGIN_ROOT}/hooks/run' <<'CURSOR_HOOK_EOF'
{"content":"$(touch /tmp/sq-012-01-contract-1rPb0P/marker)"}
CURSOR_HOOK_EOF
```

Observed with both stdin and heredoc transports:

```text
status: 127
stdout: ""
stderr: "/bin/sh: 1: /tmp/sq-012-01-contract-1rPb0P/plugin: not found\n"
marker: absent
```

The stdin is not executed, but the hook does not exit 0 or stay silent. The importing harness sees a failed hook on every event. With args, Claude Code's direct executable spawn still handles the path correctly. This is not a proposal to replace that spawn with a shell-form hook.

Fix scope: one repair of the launcher/manifest boundary and its dropped-args coverage. Add a copied plugin root containing spaces for both transports, keep the direct-parent assertion with args, and establish a command representation that works for both consumers. Do not blindly add literal quotes to an exec-form command without proving Claude Code resolves it. If these paths cannot be supported by this dual interpretation, the coordinator needs an explicit amendment of CC1 before treating them as excluded.
