Locations: `test/daemon/died-startup.test.ts:36` and the deleted
`src/core/store/index.ts`.

The row requires imports, including dynamic imports, to follow the defining
module and requires behaviour to stay unchanged. The `DRIVER` template still
contains:


removes `src/core/store/index.ts`, so that build contains `core/store/open.js`

writing `registered`. Both cases then spend 60 seconds waiting for that file.
This is the exact failure in the candidate's Node 24 CI job, not a timing guess.

Node's native `import(new URL(name, daemonUrl))`:

```text

```

Fix, sized for one worker: change the embedded URL to `../store/open.js`.
Verify `test/daemon/died-startup.test.ts` at the repaired candidate, and require
passing candidate CI. Do not restore the barrel. The source rewrite walks the
outer TypeScript syntax; it does not rewrite code inside this template string.
