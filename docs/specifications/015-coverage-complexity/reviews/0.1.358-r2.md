## B1: the loader's original blob is preserved

**Proven resolved.** `src/runners/node-test/runtime/recorder.cjs:56` and `src/core/code/coverage/own.ts:58`.

Real tsx 4.23.15 therefore sees the variable while its transform module initializes and keeps `sourcesContent`. When there is no detectable entry, the recorder removes the variable immediately. ## Repair cost

**Verified by source and experiment.** The recorder adds no load hook, per-module hash, source read, or sidecar write. It calls `hideCoverage` once at the already-detected entry, or immediately when no entry can be seen. The existing `preload` condition already runs on each resolve. For an own map, mapping now takes the embedded text and removes the old fallback source read. More source text travels in the payload; this is the measured cost.
