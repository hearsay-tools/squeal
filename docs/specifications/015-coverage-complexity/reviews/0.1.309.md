## What fits

- **D9, complete loader map:** `LoaderBuild.advance` includes the initial listing, each result/record lookup and its closure walk in budgeted work. The cache returns `null` until all rows are read. A reading-only step seeds and judges nothing. `reseedDue` survives those steps. Invalidation drops the partial map, conditions and signatures before continuation.
- **D10, one pace:** the daemon creates one `Pace` and passes that same instance to writer and code pass. The writer checks `due()` again after each wait; the pass checks it before measuring a step. The combined fake-clock test covers writer/step alternation, each unit's wait and a share below 0.55. This removes S2's two independent budgets. Reactive worker callbacks still charge their work to that shared pace.
- **D4, reads by path:** the changed state queries preserve rows, ordering and filters. The independent comparisons also check duplicate paths, empty paths and worktree separation. Complexity-only state reads serialize identically to the old implementation.
- **D9, replacement identity:** the upsert makes `recorded_at` strictly increase at each write to a key, even at the same or a lower clock value. A ready loader refreshes its stored time, and the signature includes that time. Replacing a record at an already judged key therefore judges again. Tests cover both coverage directions across the direct and cached paths. The upgrade's changed signature causes one judgement with no transition for unchanged records.
- **D4, compatible index:** the opener checks for the index before taking a write lock and checks again inside it. An indexed store takes no write lock merely to open. Readers do not create the index and return the same records without it. Schema version stays 1. The older code can keep using the indexed database; SQLite updates the covering index for its writes too.
- **Scope and bytes:** no scheduler or watcher source changed. The daemon delta is the agreed four lines. Record mapping, encoding, provider version 2, and result-key code did not change. Delivery/status rendering source did not change. Existing text/payload, coverage-off, package and version-sensitive tests pass. The rebuilt bundles match the committed files at version 0.1.309.
