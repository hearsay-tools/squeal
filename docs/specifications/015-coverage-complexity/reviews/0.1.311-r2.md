## Round-1 blocker

### B1: proven, repaired on this candidate

The original same-body rename reproduction is quiet through `createCodePass`. The committed `seed.test.ts` regressions and the independent cases above cover both sides of the seed cursor, a new destination file, chained moves, a later body edit, and real additions/removals.

The seam now carries the facts the complexity pass already knows. `PassReport.moves` returns `judged.moves`, and `PassReport.removed` returns `judged.removed`. R10 changes `pass/pass.ts` by those two lines only; `pass/types.ts` adds only the agreed readonly fields. An edit passes them to the seed before invalidating the loader map. A recount drops the seed instead.

`Seed` retains the original file positions. It records functions that leave an unseeded file and follows those that arrive elsewhere. Arrivals in a file already seeded, or outside the initial file list, are seeded before the next normal batch. A move from a file already seeded uses the state moved by the complexity pass. Removed identities stay excluded from the old inventory, so a later addition under the same name remains new. This closes the round-1 proof without suppressing genuine first-seen failures.

**Location:** `src/core/code/crap/seed.ts:78`, its `#leave` call to `#hadOf` at line 101, and `src/core/code/pass/index.ts:226`.

The source confirms that `cache.follow` runs before `pace.due()` and before `pace.measure`. `Seed.follow` reads each affected unseeded source's original count once, synchronously, with no step budget or yield. The cached original inventory avoids repeat reads for the same source, but a wide edit still reads every distinct source in one call. The committed seed timing cases do not measure this edit path.

One `Seed.follow` call did **1,007 count reads in 67.9 ms at load 29.1**. This directly measures the seed's new follow-up phase, not an end-to-end rename through the daemon. It does not prove that a real edit holds the main thread over 100 ms. The potential bound/share regression is therefore plausible, not a blocking finding. B1's behavioral repair passes.
