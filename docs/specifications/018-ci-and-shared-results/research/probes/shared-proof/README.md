# shared-proof probes (throwaway)

Throwaway material for `research/shared-proof.md` (row 018-21). Not product code or tests. Nothing here runs cezar's test suite: Squeal runs lookup-only, and no probe calls `squeal run`.

- `fetch-ci.sh`: read-only `gh api` / `gh run view --log` calls. It saves cezarion's `ci.yml` runs (merge_group, push) since `$SINCE`, their jobs, and the logs of the Vitest shard jobs whose test step ran and of the Squeal export and publish jobs. Output goes under `$TMPDIR/sp/data` (not committed: about 100 MB of logs).
- `ci-cost.mjs <data dir>`: from that data, per shard job: job wall, test step wall, Vitest's `Duration` and the sum of its phases. It sorts them into groups (merge group before cezarion#3151, merge group recording per Squeal tag, push to main), pairs shards by head SHA, and lists the export and publish job walls and which merge-group runs since cezarion#3176 ran their shards. Output: `out/ci-cost.txt`.
- `count.sh <clone> <node bin dir> <label>`: in a fresh cezar clone, it removes the clone's `.git/squeal` (set `KEEP_STORE=1` to keep it), starts Squeal 0.1.426 with that Node, and saves `squeal status --full --json` every 15 s until three listed reads agree (`MIN_READS=n` reads at least n times). Then it saves `status --full` and `status`, and stops the daemon. It uses `env -i` with a temporary `HOME` and `XDG_RUNTIME_DIR` under `$TMPDIR`. Only git's proxy and CA variables pass through.
- `decay.mjs <clone> <export.json>...`: for each export and each later first-parent main commit, it counts the exported files whose closure and observed paths have the same blob (and listings the same names) at both commits. This is the D11 match rule with equal environments and a fresh store.
- `ci-control.mjs <data dir>`: per merge-group and push run in which all four Vitest and all four cockpit E2E shards ran, the ratio of the Vitest test-step sum to the E2E sum. The E2E shards are the same run's control for runner speed. Output: `out/ci-control.txt`.
- `parts-cmp.cjs <parts dir> <blobs.tsv>`: sorts the test files of downloaded `squeal ci record` parts by why an export would leave them out (`sharedNames`, an input with no evidence, other content than the commit, a recursive listing). Output for run 42883978163: `out/parts-cmp-13582fdd.txt`.
- `key-paths.cjs`, `key-listings.cjs`, `q.cjs`: the read-only checks behind "why the first start misses". For each exported closure path or listing, they compare the commit with the clone's disk and its store's `file_hashes`, and `q.cjs` runs one SQL query on a throwaway clone's store.
- `out/decay.txt`, `out/export-left-out.txt`, `out/main-line.txt`: `decay.mjs`'s output, the export job's left-out lines for runs 42873763583 and 42883978163, and main's first-parent line from `ef0c1ff0`.
- `out/counts/`: the outputs that `shared-proof.md` quotes. `<label>/reads.txt` holds the read-by-read counts, `<label>/meta.txt` holds the commit, Node, start and end times and load, and `<label>/status-full.txt` holds the final full status. The labels: `a-*` is the clone at afd1b777 (published), `b-*` is at efcfb0e3 (no ref; the reader takes 9dd2ca62), and `c-*` is a second fresh clone at 13582fdd (published). `-n26`/`-n24` names the Node, and `-restart` is the second start on the same store. `c-n26-long` is a first start watched for 11 minutes.
