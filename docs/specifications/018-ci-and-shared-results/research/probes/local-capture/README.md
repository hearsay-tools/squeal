# Probes for topic local-capture (row 018-22)

Throwaway. These scripts and outputs back `../../local-capture.md` and are not product code. Nothing here is imported by Squeal or its tests. Run them only from a scratch directory under `$TMPDIR`; they never start an agent CLI and never write to a checkout.

Run on 2026-11-09, Node v24.22.1, Vitest 5.0.3 (this worktree's `node_modules`), Squeal source at `57fda39b7` (0.1.419).

- `manual-runs.mjs --from <day> --to <day> --json <out> --skip <session id>`: test runs agents started themselves, from Claude Code transcripts (main and subagent files) under `~/.claude/projects/-home-agent-projects-{squeal,cezar}*` and Codex rollouts under `~/.codex/sessions/2026/11/*` whose `cwd` is in either repository. Read only. The classifier is copied from `specifications/005-agent-adoption/research/probes/adoption-baseline/metric.mjs` (`classifyTest`), with two additions: the runner word must stand in command position (only `timeout`, `nice`, `env`, assignments and `pnpm exec`/`npx`/`npm exec` before it), and `node <script> --test` is not node:test (cezar's `check.mjs` takes a `--test` flag). The raw JSON holds command text from transcripts, so it stays in `$TMPDIR` and is not committed.
- `summarize.mts <runs.json> <worktree>` (through the worktree's `tsx`): the counts in `out-manual-runs.txt`, plus each command passed to Squeal's own recognizer (`recognizeTestCommand` with `commandContext(readPolicy(root), root, root)`, as `deny.ts` builds it).
- `squeal-seconds.mjs <runs.json> <file-ms.json>`: prices squeal's manual runs at the mean file-level `duration_ms` Squeal's store recorded for each matched test file in the window. `file-ms.json` came from a copy of `/home/agent/projects/squeal/.git/squeal/store.sqlite` (with `-wal`, `-shm`), 2026-11-09 14:08 local, deleted after use. Vitest 5 prints only percentages in its agent summary, so squeal's runs carry no summed seconds of their own. Output: `out-squeal-seconds.txt`.
- `config-local.mjs <fixture> '<argv>'...`: `createVitest` on a one-project fixture (`vitest.config.mjs` with `include: ["test/**/*.test.js"]`, one test file, `node_modules` a symlink to this worktree's), once with the options Squeal's daemon passes (`src/runners/vitest/adapter.ts` `#start`, coverage off) and once per command line parsed by Vitest's own `parseCLI`. Prints the per-project `serializedConfig` leaves that differ, minus the fields Squeal drops from the key (`sequence.seed`, `disableColors`, `isAgent`, `maxWorkers`). Resolves config only; no test runs. Run as `env -i PATH=$PATH HOME=<scratch> CLAUDECODE=1 node config-local.mjs ...`. Output: `out-config-local.txt`.
- `shim-reach.sh <scratch dir>`: a fixture with a fake `node_modules/.bin/vitest` (no install, no network, scratch `HOME`, `npm_config_offline=true`) and a `vitest` shim first on `PATH`; prints which of 11 command forms reach the shim. Output: `out-shim-reach.txt`.
- One functional check, not scripted: in the same fixture, `vitest run -t '^a$' --reporter=json` reported test `a` passed and test `b` skipped, exit 0.

Load: the one-minute load was 21 to 37 on 24 vCPUs during these runs; no timing was measured.
