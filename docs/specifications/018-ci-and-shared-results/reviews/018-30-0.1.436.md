## Blockers

### B1. Proven: the version probe's timeout does not bound the wait

Location: `src/core/node-pin.ts:221`, especially the timeout at line 225.
Callers: `src/core/daemon/ensure.ts:223` and
`src/core/status/snapshot.ts:284`.

The brief requires that lookup never hangs and that an unusable candidate
falls back to the caller's Node. `probe` uses synchronous `execFileSync` with
`timeout: 2000` and the default kill signal, SIGTERM. The synchronous call
still waits for the child to exit after that signal. A candidate which ignores
SIGTERM never returns to the catch, so lookup never returns `missing` and
daemon start never reaches its fallback. A status read that needs the pin
also gets stuck, inside its read transaction.

Reproduced on the exact candidate with an isolated HOME and an nvm-shaped
tree. No real version-manager tree was read or changed. The candidate script
ignores TERM and waits forever. An independent supervisor kills the entire
probe group after five seconds, so the reproduction leaves no child behind.

Run this from the candidate root (uses the already installed `tsx` loader):

```python
import json, os, pathlib, signal, subprocess, tempfile, time

repo = pathlib.Path.cwd()
node = "/home/agent/.nvm/versions/node/v26.13.0/bin/node"
with tempfile.TemporaryDirectory(prefix="squeal-node-timeout-") as tmp:
    base = pathlib.Path(tmp)
    root, home = base / "project", base / "home"
    root.mkdir()
    home.mkdir()
    (root / ".node-version").write_text("99.1.2\n")
    binary = home / ".nvm/versions/node/v99.1.2/bin/node"
    binary.parent.mkdir(parents=True)
    binary.write_text('#!/bin/sh\ntrap "" TERM\nwhile :; do /bin/sleep 1; done\n')
    binary.chmod(0o755)
    env = {"HOME": str(home), "PATH": str(home / "empty"),
           "N_PREFIX": str(home / "n")}
    script = base / "probe.mts"
    script.write_text(
        "import { pinnedNode } from " + json.dumps(str(repo / "src/core/node-pin.ts"))
        + "; console.log(JSON.stringify(pinnedNode("
        + json.dumps(str(root)) + ")));\n"
    )
    started = time.monotonic()
    child = subprocess.Popen(
        [node, "--import", str(repo / "node_modules/tsx/dist/loader.mjs"), str(script)],
        env=env, start_new_session=True,
        stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True,
    )
    try:
        print(child.communicate(timeout=5))
    except subprocess.TimeoutExpired:
        os.killpg(child.pid, signal.SIGKILL)
        print("outer timeout", round(time.monotonic() - started, 2), child.communicate())
```

Actual result: `outer timeout 5.01 ('', '')`. Expected: a bounded lookup
returns `{ reason: "missing", wanted: "99.1.2" }` and permits fallback.

Repair size: one worker, `node-pin.ts` and focused regression tests. Make the
probe termination enforce its bound even when a candidate ignores TERM.
Use a forceful kill policy and cover the elapsed-time/fallback behavior with
an independent supervisor, so a regression cannot hang the test runner.
Preserve the synchronous interface and the existing fast paths. No status
rewrite is needed.
