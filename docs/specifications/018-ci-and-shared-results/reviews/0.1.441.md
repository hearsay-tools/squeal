## Verdict

### B1. A cut Node 26 stack does not prove a preload failed

**Proven.** `src/runners/observe/signature.ts:39-41,63-64`.

Spec 001 D11: “a project's own module load gets none.” The signature must identify
`ERR_INVALID_PACKAGE_CONFIG` raised while loading a preload. A command line containing
`--require` establishes that the process had a preload. It does not establish that
the preload caused the error. Node 26 cuts both stacks at the same internal frame.

Reproduction, entirely in a temporary directory:

1. Write an empty `pre.cjs`.
2. Write `bad/package.json` containing `{broken`.
3. Write `main.cjs` containing:

   ```js
   require("node:module")
     .createRequire(__dirname + "/bad/main.cjs")("missing-package");
   ```

4. Capture the exception from `execFileSync` of Node 26.13.0 with
   `['--require', absolutePre, absoluteMain]`, `cwd` the temporary directory and
   `stdio: 'pipe'`. The preload finishes successfully. The entry then fails while
   resolving its own module under `bad/package.json`.
5. Pass that exception's message as `CheckError.message` to `recorderSignature`,
   with a nonempty recorder file list and `inNodeOptions: true`.

Actual: `a --require preload makes Node parse the nearest package.json (ERR_INVALID_PACKAGE_CONFIG)`.
Expected: `undefined`. Node 22.19.0 and 24.22.1 return `undefined` for the same call.
The Node 26 error ends at `wrapModuleLoad (node:internal/modules/cjs/loader:261:19)`;
the stack has lost the frame that would distinguish the two causes.

The adapter path was also verified, rather than assuming any child loses its
recorder. An observing Vitest fixture ran the above child with
`env: { SQUEAL_OBSERVE: '{"out":""}' }`. This is the existing foreign-recorder
boundary in `observe/spawn.cjs`, also used to leave a nested Squeal's subtree
alone. The fixture's run still used the recorder. Its child did not. The adapter
returned:

```text
outcome: fail
recorder: a --require preload makes Node parse the nearest package.json (ERR_INVALID_PACKAGE_CONFIG)
summary: Command failed: <node> --require pre.cjs main.cjs; ran under Squeal's recorder in NODE_OPTIONS: a --require preload makes Node parse the nearest package.json (ERR_INVALID_PACKAGE_CONFIG)
```

With an active recorder inside this particular child, its resolve-hook frame
makes this probe's stack distinguishable and it gets no label. That narrower
case does not rule out errors from a subtree outside that recorder's reach.

**Repair:** remove `CUT_PRELOAD` and the command-option fallback. Preserve the
0.1.440 `PRELOAD` rule. Expect no preload label for an indistinguishable Node 26
stack in both the signature test and the adapter fidelity test. Keep the
own-module negative case with a successful preload. This is one focused worker
repair; it changes no outcomes or fingerprint. The coordinator confirmed there
is no spec amendment accepting a wrong label. A missing label on a cut stack is
acceptable; a wrong one is not.
