## Row 024-03: Antigravity adapter and recorded hook fixtures

- **Outcome**: Implement the Antigravity hook adapter under `src/harness/antigravity/` (all five hook entries) with sanitized hook JSON fixtures and unit tests.
- **Read**: `docs/vision.md`, `docs/styleguide.md`, `docs/specifications/024-antigravity-adapter/spec.md` (D1–D5, D8, Testing), `status.md`, `research/wave-0-checks.md` (sections 2 and 4), and `reviews/0.1.601.md` ("Inputs for the next wave" items 2–4). Use `src/harness/codex/{input,output,kept,hook,handlers,hooks,run,main}.ts` and `src/harness/pi/run.ts` as precedents.
- **Shape**: slice.
- **Starting seam**: `src/harness/antigravity/input.ts` and `src/harness/antigravity/output.ts` (`src/harness/antigravity/command.ts` already exists from Wave 1).
- **Contract**:
  1. `input.ts`: parse camelCase protojson stdin (`conversationId`, `cwd`, `workspacePaths`, `hookEventName`, `invocationNum`, `initialNumSteps`, `toolCall`, `executionNum`, `terminationReason`, `fullyIdle`, `continuationActive`). Fall back to `workspacePaths[0]` when `cwd` is empty. For `PreToolUse`, extract `toolName = toolCall.name`, and for `run_command` extract `command = toolCall.args.CommandLine` and optional `toolCwd = toolCall.args.Cwd`.
  2. `output.ts`: `MESSAGE_CAP_CHARS = 10_000`; `capContext(text, command, keep)` keeping trailing primer and `keep` line whole; `injectSystemMessage` (`{ injectSteps: [{ systemMessage: { systemMessage } }] }`), `deny` (`{ decision: "deny", reason }`), `continueTurn` (`{ decision: "continue", reason }`).
  3. `kept.ts`: mirror `src/harness/codex/kept.ts` using `ANTIGRAVITY_MANIFEST` and `ANTIGRAVITY_COPIED` from `../shared/version-copies.js` and `antigravityCommand` from `./command.js`. Retain the copy before spawning a daemon or printing a launcher command.
  4. `handlers.ts`: consumer is always `(conversationId, "main")`.
     - `sessionStart`: `keepAntigravityVersion` when `usesSqueal(location)`, `startSession({ session_id: conversationId, source: "startup" }, location, kept)`, return `injectSystemMessage` with `skillLine(kept)`.
     - `preInvocation`: when `(invocationNum ?? 0) === 0`, `submitPrompt(..., { register: true })`; when `invocationNum > 0`, `deliver(context, deps, true)`; return `injectSystemMessage` with `registeredSkillLine`.
     - `preToolUse`: `EDIT_TOOLS` (`write_file`, `edit_file`, `write_to_file`, `replace_file_content`, `multi_replace_file_content`) -> `denyOnRegression` when `interrupt.onRegression` is on; `run_command` -> `testCommandOf` with `toolName: "Bash"` and `cwd: toolCwd ?? cwd`, then `denyCurrentTestCommand` when `testCommand.denyWhenCurrent` is on. Return `deny` or `null` (empty stdout, never `{}`).
     - `stop`: if `terminationReason` is non-empty and not `"NO_TOOL_CALL"`, or if `fullyIdle === false`, call `endTurn` without handoff and return `null`. Otherwise `active = continuationActive === true || (executionNum ?? 0) > 0`; call `stopTurn({ session_id, stopHookActive: active, harness: "antigravity", ...(active ? { quiet: true } : {}) }, location, deps)`; return `continueTurn` on news/block or `null`.
     - `stopSlowTier`: skip (return `null`) on non-empty non-`"NO_TOOL_CALL"` `terminationReason` or `fullyIdle === false`. Otherwise call `stopSlow({ session_id, harness: "antigravity" }, location, deps)` and return `continueTurn` or `null`.
  5. `hooks.ts`, `run.ts`, `main.ts`, `entries/{session-start,pre-invocation,pre-tool-use,stop,stop-slow}.ts`: `HandOff` + `writeThenCommit` so reports commit only after stdout succeeds; every error abandons `HandOff` and emits empty stdout (never `{}`). `pre-tool-use` arms an unref'd `1_500` ms internal fail-open deadline (injectable for tests) that abandons `HandOff` and exits 0 silently.
  6. Fixtures under `test/fixtures/antigravity-hooks/` matching `research/wave-0-checks.md` section 4 (placeholder UUIDs and `/home/user/project` paths) and unit tests under `test/harness/antigravity/`.
- **Ownership**: `src/harness/antigravity/{input,output,kept,hook,handlers,hooks,run,main}.ts`, `src/harness/antigravity/entries/*.ts`, `test/fixtures/antigravity-hooks/**`, and `test/harness/antigravity/*.test.ts` (except `command.test.ts`, `fast-path.test.ts`, `plugin-schema.test.ts`, `version-bump.test.ts`). Leave `src/harness/antigravity/{command,build}.ts`, `plugins/**`, `src/cli/**`, `src/core/**`, `package.json`, `scripts/**`, `.github/**`, and `squeal.config.json` alone.
- **Done when**: Unit tests pass for all 5 handlers, 5 edit tool names, `run_command` deny, empty stdout on allow/error, 1,500 ms fail-open deadline, `Stop` guards and `stop` -> `stop-slow` handoff, `$PLUGIN_DATA` copies/pruning, and `writeThenCommit`; `pnpm run lint`, `pnpm run typecheck`, and `pnpm run check:private` pass.
- **Role**: Use `/worker`.
