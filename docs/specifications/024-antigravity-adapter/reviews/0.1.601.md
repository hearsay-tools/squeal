## Blockers

### B1. A pre-existing Antigravity plugin can become installer-owned and be deleted

**Proven.** `install.sh:421` and `install.sh:434`, with the version filter at `install.sh:150`.

D1 requires ownership only for a plugin installed by this script. The Wave 1 contract is explicit: "Record `antigravity` in `$OWNED` only when Squeal was not already installed at `~/.gemini/config/plugins/squeal/plugin.json` before `install.sh` ran."

`install_antigravity` uses `current=$(installed antigravity)` for both version selection and pre-existence. `installed` returns nothing unless the manifest's version is entirely numeric and dot-separated. A pre-existing plugin with a valid prerelease version such as `0.1.599-local`, or a manifest without a readable version, therefore looks absent. The update replaces it, records `antigravity`, and a later `--uninstall` removes the user's plugin.

An isolated-HOME Python probe on the boat sandbox exercised the candidate's unmodified `install.sh`. It created a pre-existing root `plugin.json`, a local release archive containing an Antigravity plugin at `0.1.601`, and a fake `agy` implementing the observed `--version`, `help plugin`, install-copy and uninstall behavior. It ran `sh install.sh --antigravity`, read the ownership record, then ran `sh install.sh --uninstall`. Only the pre-existing manifest version differed between cases:

```text
pre_existing_version=0.1.599       install_exit=0 owned=""            uninstall_exit=0 plugin_remains=true
pre_existing_version=0.1.599-local install_exit=0 owned="antigravity" uninstall_exit=0 plugin_remains=false
pre_existing_version=<missing>    install_exit=0 owned="antigravity" uninstall_exit=0 plugin_remains=false
```

This is a break of the explicit ownership contract, not a CLI discovery problem. The plain-version control demonstrates that the existing ownership test covers only the accepted-version path.

**Worker-sized fix:** in `install_antigravity`, snapshot `[ -f "$ANTIGRAVITY_PLUGIN/plugin.json" ]` before the install. Use that fact alone to decide whether to record ownership. Keep version parsing for the same-version download skip and post-install verification. Preserve ownership already recorded by an earlier installer run. Add isolated-HOME regressions beside `test/cli/install-antigravity.test.ts` and `test/cli/install-antigravity-uninstall.test.ts`: update a pre-existing prerelease manifest and a manifest without a version, assert no new ownership record, and assert uninstall preserves the plugin. Also retain the absent-plugin control that must become owned.
