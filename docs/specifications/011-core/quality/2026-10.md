## Slices

1. Two places release a tier's claim on a superseded file, both added by 011-71: `#requeue` (`src/core/scheduler/scheduler.ts:978-981`) and `recordTier` (`src/core/scheduler/tiers.ts:594-597`). Give `Ledger` (`src/core/scheduler/ledger.ts:413`) one method that ends this tier's claim at `key` only, and call it from both places.
2. Three private copies of one process check (`kill(pid, 0)`, with `EPERM` counted as running): `pidRuns` (`src/core/status/slot-holders.ts:25-33`, 011-58), `alive` (`src/harness/shared/version-copies.ts:185-193`, 005-73) and the older `alive` (`src/harness/opencode/bridge-turn.ts:162-170`). Export one `listText` ("a", "a and b", "a, b and c") from `src/core/text.ts` and use it in all three.
4. The `engines.node` parse exists twice: `nodeFloor` (`src/harness/build.ts:85-94`) and `manifestFloor` (`src/harness/opencode/host.ts:23-31`), with the same regex and the same error text. `build.ts` also reads `package.json` twice (`rootVersion` at `:73`, `nodeFloor` at `:86`), and both bundle option sets call `nodeFloor()` twice (`build.ts:130,134`, `src/harness/opencode/build.ts:64-65`). Export one `floorOf(manifestText)` from `host.ts`, which is the only place the OpenCode plugin bundle can reach (`test/harness/opencode/package.test.ts:77-78`). 5. Two printers do not use 011-76's `atText`. `namedFailures` (`src/cli/named-file-lines.ts:180-182`) says it prints each failure "as status lists it", but it formats `at path:line:column` by hand. Use `atText(f.location, f.testFileFrame)` in both. In the same slice, `samePosition` (`src/core/delivery/attribution.ts:142-144`) copies the non-null branch of `sameLocation` (`src/core/state/derive.ts:155-158`): export one of them.
6. The yield remainder is rounded in two ways. `yieldId` (`src/core/status/standing-groups.ts:37-42`, 011-57) uses `Math.round(remainderMs / 1_000)`. `yieldText` (`src/core/status/next-step.ts:67`) also clamps the value at 0. `remainder` (`src/core/scheduler/yields.ts:207`) is negative when a file runs past its last-known duration. The same line also writes "30 s" as a literal, which restates `YIELD_REMAINDER_MS` (`yields.ts:23`). Add one `remainderSeconds(tier)` beside `yieldText` and use it in both, and build the "30 s" text from the constant.
