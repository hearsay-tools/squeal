### 2. Proven: the moved order and width have test evidence

Locations: `src/core/scheduler/scheduler.ts:1059`, `src/core/scheduler/slow-tier.ts:287`, `src/core/scheduler/admission.ts:305`, `test/scheduler/admission.test.ts:92`.
