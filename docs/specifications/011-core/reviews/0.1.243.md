## Blockers

### B1. Proven: pytest long and short frames are lost when a path contains a space

`src/core/status/test-frame.ts:24` defines `PYTEST_ENTRY` with `[^\s:]+`. A space is valid in a test directory or filename. Pytest prints it literally. The new parser drops both the helper and test positions, so `prefixOf` returns `null` and the failure gets no test-file frame.

This breaks 011 C5's 2026-10-21 amendment: a failure in a helper "also names the first frame in [the check's own test] file" when the stored stack holds it. It also breaks the pytest part of 011-64 R2 test 2. Nothing in that contract excludes paths with spaces.

**Reproduction, verified on the pinned source.** In a scratch directory, create these two files:

`test frames/helpers.py`:

```python
def check_total():
    assert False
```

`test frames/test_frames.py`:

```python
from helpers import check_total

def test_call():
    check_total()
```

Run real pytest 9.1.1 on Python 3.13 with Squeal's `squeal_pytest` plugin, once per `--tb=short`, `long`, and `native`, capturing `SQUEAL_PYTEST_EVENTS`. Pass the event streams through the unchanged `parsePytestEvents` and `readBatch`, then call the candidate's `testFileFrame` with the resulting check and errors. The short stack is:

```text
test frames/test_frames.py:4: in test_call
    check_total()
test frames/helpers.py:2: in check_total
    assert False
           ^^^^^
E   AssertionError
```

All three stored errors name `{ path: "test frames/helpers.py", line: 2, column: 1 }`. Results:

```text
short: testFileFrame = null
long:  testFileFrame = null
native: testFileFrame = { path: "test frames/test_frames.py", line: 4 }
```

Expected for each style: `{ path: "test frames/test_frames.py", line: 4 }`. Both long and short stored stacks contain that exact position. This is independent of host load and the npm-cache issue.

**Fix scope:** one repair to `test-frame.ts` that accepts spaces in pytest entry paths, with real long and short recordings for a path with a space and a regression for native style. Preserve exact path matching and the missing-frame cases. No adapter, stored location, fingerprint, key, or version change is needed.
