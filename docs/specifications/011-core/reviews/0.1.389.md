## Nits

### N1: narrow the new `settle` comment's exception promise

**Proven documentation defect; non-blocking.** `src/harness/shared/hand-off.ts:43` says `settle` never throws. The false branch at line 49 calls `abandon()` outside the catch. A `close` callback that throws therefore propagates. Cheap reproduction:

```ts
const handOff = new HandOff();
handOff.take(new PreparedReports(), () => { throw new Error("close failed"); });
handOff.settle(false); // throws "close failed"
```

The previous Pi and OpenCode false-verdict paths also called `abandon()` without a catch, so this is no runtime regression. Narrow the comment to say that commit failures are swallowed and reports remain owed. Do not change exception handling merely to match the current comment: the row requires existing caller behavior to remain.
