## 1. Proven: the candidate meets the relaxed retention rule

`writeCoveredFiles` scans only this worktree's existing records when it writes a new record. `idleSince` (`src/core/store/covered-files.ts:143`) returns `null` immediately if any covered reference is queued or running. The delete requires a non-null idle timestamp, so that write cannot delete such a record.

For an idle record, the timestamp starts no earlier than its own `recorded_at`. The insertion initializes it with `recordedAt = now`, or leaves it null while pending. Later updates take the maximum of the earlier idle timestamp or original write time, the ledger's first-write bound, and known exits; the missing-file branch uses the current write time. None of these paths moves a valid record's timestamp before its own write. Deletion requires that timestamp to be at least 600,000 ms old. Thus the minimum lifetime is 10 minutes from the record's own write, independent of whether a later exit was lost.

The disposable probe checked three discriminating cases:

- **R2 reproduction under the new rule:** write B's request record at minute 0, complete B, observe idle at minute 1, edit/queue at minute 3, remove at minute 5, restore at minute 6 through a real stored passing result. The restored state has no pending phase or exit time. A record write at 599,999 ms retains the record. A write at minute 11 prunes it. This is now allowed: it lived more than 10 minutes from its write, and no covered file is pending at either pruning check.
- **Pending at a later write:** the request's record remains readable at minute 11 with B queued, then at minute 30 with B running. Its age alone cannot delete it.
- **Idle from its own write:** the record remains readable at 599,999 ms and is pruned at 600,000 ms. This checks the minimum lifetime boundary without relying on a later exit time to extend it.

The unchanged candidate retains known exit times and its handoff bound, so it often keeps records longer than the amended minimum. R3 does not require the lost removal/restoration exit to survive.
