Changing that helper to satisfy the wording would change another contract.

No code repair is indicated. A coordinator documentation follow-up should amend decision 2 and the row to say that the plan owns tier membership and order, while this compatibility check sums the longest last-known file duration. A future change to timing estimates or a view of the whole queue needs its own behavior row and failing example.
