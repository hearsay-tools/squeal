Releasing worker capacity then permits exactly one retry, which passes and clears the failure. These assertions distinguish worker-pool contention from an occupied slow slot; the test cannot pass solely by creating the original occupied-slot case.

The occupied-slot regression and the store-based receipt/status assertions retain coverage with the same honest capacity words. No scheduler field, admission rule or priority changed.
