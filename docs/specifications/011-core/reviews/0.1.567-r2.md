`shift` first changes the published overrun in memory. It then tries the store write with a zero-length busy slice. On SQLite busy it drops the write. It records no dirty state and schedules no retry. Later checks find the overrun already present in memory, so they need not publish it again. A quiet hung tier can keep the stale row until some other event changes the row or the tier ends.
