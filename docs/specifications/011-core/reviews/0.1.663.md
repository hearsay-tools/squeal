## Blockers

### B1. Proven: scratch cleanup signals a group outside its folder

Location: `test/helpers/scratch.ts:127-128`, called by `namesFolder` at line 123 and group selection at lines 89-93.

Row 011-431 requires a fixture-owned folder to end its own writers before removal. The helper instead accepts any argument, environment value or working directory containing `${dir}/` anywhere. An absolute path that embeds `dir` later in its text is a different tree, yet this predicate treats it as inside `dir`.

One probe ran with `timeout 20 pnpm exec tsx /tmp/squeal-review-663-scratch.mts`. It made a scratch folder, then a separate temporary folder. It created `outside + scratch.dir + "/child"` under that second folder. A detached Node child ran there, with no scratch path in its arguments or explicit environment. Its IPC ready message arrived before removal. Then the probe called `scratch.remove()` and read the child's exit.

The relevant setup is:

```ts
const scratch = scratchDir(join(tmpdir(), "sq-review-owned-"));
const outside = mkdtempSync(join(tmpdir(), "sq-review-other-"));
const unrelatedCwd = `${outside}${scratch.dir}/child`;
mkdirSync(unrelatedCwd, { recursive: true });
// Spawn a detached sleeper with cwd: unrelatedCwd; await its IPC ready message.
scratch.remove();
```

Actual output, with generated paths shortened:

```text
scratch: <tmp>/sq-review-owned-A
unrelatedCwd: <tmp>/sq-review-other-B/<tmp>/sq-review-owned-A/child
before: [899582]
after: []
exit: { code: null, signal: "SIGTERM" }
```

This is a real wrong-process signal, not a PID-reuse hypothesis. The older-group and unrelated-marker tests pass because they do not exercise a false substring match.

Fix, one worker: use path boundaries for ownership. Compare the cwd as a path. Parse supported argument and environment forms before comparing paths; an arbitrary substring cannot prove ownership. Add a regression with this separate tree and require its child to remain alive after removal. Retain coverage for the owned writer, cwd, older groups and environment forms used by callers.
