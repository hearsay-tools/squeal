## Blockers

### B1. Proven: named `--full` omits the detail block and uses the wrong command base

Location: `src/cli/status-wait-lines.ts:326`, at the boundary changed by `src/core/status/format-status.ts:56`.

Contract: design 011-24 section 1.4 says the worktree status prints with `--full`. R3's done-when says “`--full` gives today's output.” Section 1.2 defines that full output as all outstanding groups followed by the detail block. Section 3 requires a command that advances the named file. The review brief also requires each group's command to be right for its files.

`namedText` enters its full branch, but passes only `allNotes` to `formatStatus`. Before this candidate the formatter printed details by default. It now needs `full: true`. Both the named snapshot and the named wait therefore print the short status, with a `More: squeal status --full` hint, even though that flag was already supplied. Worktree, daemon, inheritance, the per-file reasons, schema and notes are absent. `--notes` happens to work because `allNotes` implies `full` in the formatter.

A CLI probe used a temporary fake repository and the real built `main`, with one listed test file and no daemon. It changed no candidate file:

```text

status --wait 0 a.test.ts --full -> exit 3, Worktree=false, More=true
status a.test.ts --notes -> exit 3, Worktree=true, More=false
```

A direct `namedText` probe with the existing `test/evals/status-snapshot.ts` seed gave the same result for a named snapshot and a named wait. With `selection.base = "packages/child"` and an outstanding root-relative `src/a.test.ts`, it printed:

```text
1 test file never run at its inputs, nothing queued it (the baseline is lookup-only): src/a.test.ts; `squeal retry src/a.test.ts` runs it once
```

That retry resolves to `packages/child/src/a.test.ts` from the caller's directory. The required argument is `../../src/a.test.ts`. The new formatter also needs the selection's base.

One-worker fix: pass `full: true`, `allNotes` and `base: wait.selection.base` through this branch. Strengthen the named snapshot and named wait tests to assert the detail lines and the absence of the `More:` hint with `--full`. Add a subdirectory case with an outstanding file outside that directory. Test `--notes` with it too. Rebuild the committed bundles.
