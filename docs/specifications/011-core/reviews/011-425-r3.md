## Cause and repair

**Proven:** `buildDist` defaults to `rootVersion()` (`src/harness/build.ts:318`). Before this repair, both hook bundles in `test/daemon/symlinked-source.test.ts` reported `0.1.591`. Its `daemonSuite` uses `buildCli`, whose private manifest reports `TEST_VERSION`, `0.1.590`.

`handOver` uses the hook's version, and `succeeds` requires it to be strictly newer than the daemon (`src/harness/shared/ensure.ts:169,247`). These hooks therefore qualified to request step-down and spawn a successor. That turnover disturbed the watcher proof. The original `.600` daemon prevented turnover because both root-version hooks were older. Lowering the fixed version exposed this missed pairing.

The repair passes `TEST_VERSION` to both `buildDist` calls (`test/daemon/symlinked-source.test.ts:49`). Hook and daemon versions are now equal. The replacement predicate rejects that pair, as required for this watcher test. Notes section 7 accurately records the cause, the two failed CI shards and the pairing rule. The exact-candidate test passes.
