### `through: ["pump"]`: `runs.test.ts`, "discards a tier result whose inputs changed during the run and re-queues the file"

With a plain `quiet()`, the counts were `current: 7` where 11 is expected. The rest that `quiet()` returned held one wake: `pump`. The tier was unstable, so the scheduler re-queued the file. The re-run waits on the pump's own wait, and `Scheduler.idle()` waited through it in real time. `h.quiet({ through: ["pump"] })` does the same, so the case keeps its meaning. This is B2's finding (`backlog-tiers`, a wait after a cancel) in another place.
