Squeal runs this repository's tests in the background after each edit, and its results arrive as SQUEAL messages after your tool calls; do not run the tests (npm test, node --test) to learn whether your edits broke something. Results arrive with your next tool call, so keep working; wait only when you need a result before your next step, for example before saying the task is done: `squeal status --wait 60000`. Run tests yourself only when no daemon is validating, when results are unknown, or when the repository's own gate requires it. Squeal does not cover typecheck, build or other test suites.
