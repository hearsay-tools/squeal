## Verdict

No 007 feature fails the vision's decision filter. Every note, admission rule, observed-path key and refused flag traces to a goal, a D-section or a review blocker.

The cost of 007 is the same as 009's: copies. The pytest runner was written beside node:test (spec 003, "the closest precedent", `status.md`) by copying its parts rather than sharing them. Copied whole or nearly whole:

- the observed-paths store and its parsers;
- the observed-paths tracker class;
- the test-file walker's glob bases;
- `slashes`, `isDirectory` and `isFile`;
- the "cannot run" report and the temp-directory env merge.

The pytest runner also imports its process runner from `node-test/run/`. Inside the runner, Python's `fnmatch` is translated twice, differently. The `isDirectory` and `isFile` copies use two error rules.

`status.md` mostly matches the code: D2's admission constants, the environment-note topic, `editableDir` and `insideWorktree` shared by the refusal and the hash, the `--basetemp` per batch, `batchSize` as a policy key, the closed events file, and the all-skipped note requiring a completed tier (007-21 S1). One amendment is only half true: open question 3 moved pytest's cache into Squeal's state directory, and the daemon does pass it, but two OS-temp defaults are left (slice 5).

Three modules under `src/runners/pytest/` pass about 300 lines: `adapter.ts` (353), `runtime/squeal_pytest.py` (334) and `run/run.ts` (307).

Every slice and row below changes guarded sources, so each one re-pins or bumps `KEY_FORMAT_VERSION` by the rule in `src/core/keys/key-format.ts`.

## Slices

1. **One Python `fnmatch`.** `enumerate.ts` has its own translation (`src/runners/pytest/enumerate.ts:185`, used by `matches` at `:179` for `python_classes` and `python_functions`). It differs from `adapter-files.ts`'s `fnmatch` (`src/runners/pytest/adapter-files.ts:147`), which follows `fnmatch.translate`. `enumerate.ts` leaves a leading `^` in a set unescaped, so `[^x]` becomes a negated class where Python matches `^` or `x`. It also does not escape a backslash inside a set. Export the one in `adapter-files.ts` from its own module and call it from `matches`. Neither copy escapes a leading `]` (`[]a]`), which JavaScript reads as an empty class, so fix that in the merged one with a test.
2. **One `isDirectory` and `isFile`, one error rule.** pytest has four copies under two rules. `src/runners/pytest/adapter.ts:347`, `src/runners/pytest/graph/derive-roots.ts:273` (`isDir`) and `:281` swallow every error. `src/runners/pytest/environment/discover.ts:136` and `src/runners/pytest/environment/config.ts:110` return `false` only for a missing path (`config.ts` also for `ENOTDIR`) and throw the rest. `src/runners/node-test/adapter.ts:164` is a fifth copy. Put the pair in `src/core/fs/` with `config.ts`'s rule, as the styleguide's "never swallow an error silently" asks. A caller that must not reject keeps a catch at the call.
3. **One `slashes`, one glob-base walker, one project `cwd`.** `slashes` is defined four times: `src/runners/pytest/adapter-files.ts:191` (exported only for `adapter-environment.ts:11`), `src/runners/node-test/adapter-files.ts:68`, `src/runners/node-test/adapter-environment.ts:92` and `src/runners/node-test/adapter.ts:172`. It is written inline at `src/runners/pytest/adapter-environment.ts:241` and `src/runners/pytest/run/run.ts:127`, and `src/core/fs/paths.ts:12` already holds the same expression. `bases` and `GLOB` are verbatim copies (`src/runners/node-test/adapter-files.ts:9`, `:52`; `src/runners/pytest/adapter-files.ts:27`, `:175`). `projectCwd` (`node-test/adapter-files.ts:12`) and `projectDir` (`pytest/environment/discover.ts:33`) are one function, and `pytest/run/run.ts:81` inlines it a third time. Export `slashes` from `src/core/fs/paths.ts`, move `bases` beside `createInputMatcher` in `src/core/keys/glob.ts`, and have `run.ts:81` call `projectDir`. Crosses 003's files.
4. **`admit` returns the environment.** `Admission.outcome` and `Admission.fingerprint` (`src/runners/pytest/adapter-environment.ts:57-62`) are read only by `test/runners/pytest/adapter-environment.test.ts`. The adapter takes `.environment` alone (`src/runners/pytest/adapter.ts:135`), a ready environment carries its own `fingerprint`, and `timeout` is exactly the `unsettled` state. Return `AdapterEnvironment` and assert the state and fingerprint in the test.
5. **The cache directory has no OS-temp default.** Open question 3 (`status.md`, wave 1) moved pytest's cache and bytecode into Squeal's state directory, and the daemon always passes one (`src/core/daemon/pytest-runners.ts:114`). But `runPytest` still defaults to `defaultCacheDir` under the OS temp directory (`src/runners/pytest/run/run.ts:43`, `:287`), and `PytestAdapterOptions.cacheDir` still documents that default (`src/runners/pytest/adapter.ts:67`). Both use `pytestCacheDir`'s hash. Make `cacheDir` required in both, drop `defaultCacheDir`, and have callers that omit it pass a scratch directory. Moving `allSkippedNote` (`run.ts:249`) beside `PytestFileReport` in `run/report.ts` then brings `run.ts` under 300 lines.
6. **One ready-environment type.** `Extract<…, { state: "ready" }>` is aliased three times: `src/runners/pytest/adapter-environment.ts:64`, `src/runners/pytest/adapter-run.ts:22` and `src/runners/pytest/run/run.ts:25`. Export one `ReadyEnvironment` from `src/runners/pytest/environment/index.ts`.
