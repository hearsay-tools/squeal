### S2. Proven: the watch adds work to runs with no provider

Locations: `src/runners/vitest/ci-runtime/vitest-ci.cjs:257`, `src/runners/vitest/ci-runtime/inspector.cjs:68`.

The requested "no cost to runs without a provider" confirmation is false. Every recorded process with a raw directory installs the watch when `module.registerHooks` is available. The provider argument only exempts Squeal's own caller; it does not gate installation. The watch wraps `process.getBuiltinModule`, IPC send methods and module resolution, and performs synchronous directory/file writes while test files run. Only `withWatch` later discards these facts for `no-provider`.

Both the real no-provider fixture and the isolated probe prove this path. No timing benchmark was run, so the size of that cost is **unverified**. This is a non-blocking note under the bounded re-review rule: the no-provider export control passes and B1's reuse rule is met.

A missing Squeal records worker alone cannot disable it: a project's custom provider can still run and must remain watched. Add a no-provider control for hook identities/watch output, beside the existing custom-provider yield control.
