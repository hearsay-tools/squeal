The new loop awaits `#paused`, then continues without checking `#stopped`. The pause callback clears `#cancel` before resolving its promise. The resumed loop calls `#pass` once more with `stopped === true`. This contradicts the method comment, "No pass starts any more."

Reproduction: make the first pass return `left`; capture `then` from a `Pause`; wait until that seam is reached; call `then(); await early.stop();` with no yield between the calls. Count calls to the pass and record `early.stopped` at entry. The candidate produces two calls, with the second stopped.
