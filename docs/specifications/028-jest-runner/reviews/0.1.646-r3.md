## Blockers

### B2 remains: the root's rootDir changes the selected child's rootDir

**Proven on Jest 29.7.0 and 30.5.2.** `src/runners/jest/run/wrapper-config.ts:150` resolves the root's `rootDir`, then `:151` passes that directory into `inlineOptions`. `src/runners/jest/environment.ts:129` does the same at `:130` and `:131`. This makes an inline child without `rootDir` inherit the root's configured directory.

Native Jest's `readConfigs` passes `dirname(configPath)` as the child reader's `parentConfigDirname`. Its `readInitialOptions` uses that config-file directory when the inline child omits `rootDir`. The root's global `rootDir` and the child's default `rootDir` are distinct. The new wrapper and environment reader agree with each other but disagree with Jest.

Spec D4.1 requires the wrapper to inject the runtime "while preserving every user option". D1.2 expands projects as Jest's `readConfigs` does. Running a different passing test file cannot validate the native project's failing file.

Minimal fixture, with the command's cwd at the fixture root:

```js
// jest.config.cjs
module.exports = {
  rootDir: 'workspace',
  projects: [{
    displayName: 'unit',
    testEnvironment: 'node',
    testMatch: ['<rootDir>/unit/*.test.cjs'],
  }],
};
// unit/a.test.cjs
test('root-dir contract', () => expect('actual failure').toBe('pass'));
// workspace/unit/a.test.cjs
test('root-dir contract', () => expect(true).toBe(true));
```

The probe compared `node <jestBin> --config jest.config.cjs --runInBand --ci --cacheDirectory <fixture>/native-cache --json` with `createJestAdapter({ name: 'unit', config: 'jest.config.cjs', project: 'unit', include: [], exclude: [], args: [], env: {} }, { root, cacheDir: <fixture>/adapter-cache })`, followed by `testFiles()`, `environment()`, and `run(files, { runId: 'r3-rootdir', logDir: <fixture>/logs, timeoutMs: 30000 })`.

The committed regression at `test/runners/jest/adapter.test.ts:593` leaves the root directory at its default and sets the child `rootDir` to `'.'` at `:600`. The two bases are equal there, so that regression cannot catch this mismatch.
