### Markers and unchanged stored meanings

**Proven.** The absent marker is `sha1("\0absent")` and the empty marker is `sha1("\0empty")`. A valid entry name contains no NUL and is not empty. A sorted nonempty list joined by NUL therefore cannot produce either marker's input text. The two markers differ from each other and from the old null segment. As with other key hashes, this assumes no cryptographic collision. A nonempty directory still uses exactly the old sorted-name hash. Only keys whose closure includes an absent or empty unwatched listing change because of the markers. Tracked and nonempty listings keep their meaning. An unreadable listing is treated as absent, as the worker's design states.
