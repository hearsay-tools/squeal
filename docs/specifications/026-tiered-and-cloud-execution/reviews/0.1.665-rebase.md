## Nit N1: proven, nonblocking comment overstates transport and failure behavior

Location: `test/runner-host/remote/lane-drift.test.ts:62` and line 65.

The comment says real SSH passes no local environment variable and describes the remote Vitest run as crashing. OpenSSH can forward variables through `SendEnv`/`AcceptEnv` or set them through configuration. Its remote login can also have CI set independently. The inspected client's effective configuration forwards `LANG` and `LC_*`, not CI. The focused report proves an environment refusal, not a process crash.

One small follow-up: say this fixture models a remote login without the caller's CI variables, and that removing them aligns the fake remote's Vitest config with the already-sanitized local host. Do not strip CI in the product or weaken the environment comparison. This wording issue does not affect the fixture repair's correctness.
