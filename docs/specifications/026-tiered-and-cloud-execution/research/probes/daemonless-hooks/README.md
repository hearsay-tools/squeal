# daemonless-hooks probes (throwaway)

Throwaway scripts for spec 026's research topic `daemonless-hooks`. Nothing here is product code or a test. Delete freely. Every fixture, home directory and daemon lived under `$TMPDIR/dlh`; all were stopped and removed before commit.

- `inline.ts`: a PostToolBatch stand-in with no daemon. One fresh Node process counts complexity (`countFile`, web-tree-sitter), writes the counts to a `code.sqlite` (`openCodeStore`, `counts.put`, `files.upsertMany`, `states.list` in one transaction), and/or runs oxlint through Squeal's own provider (`open`, `inputs`, `lint`: three oxlint processes). It prints phase times in ms since the process started.
- `build.mjs`: bundles `inline.ts` with esbuild the way the plugin build bundles its CLI, and copies the WASM files beside it (`dist/code`, `dist/pytest`).
- `drive.mjs`: runs each case 15 times in rotation under GNU `time` (wall, user+sys CPU, max RSS), pausing while the one-minute load is over 24 at the start of a round. Cases: Node's floor, the committed `post-tool-batch.mjs` with no config (Node plus the 709 KB hook bundle), the probe in each mode on 1, 3 and 5 real TypeScript files, a raw `oxlint --format json --threads 1` run, `eslint` 10.13.0 (3 core rules) on one 224-line `.mjs` file, `biome lint` on one file. `CASES=extra` times `git status`, `git diff --name-only HEAD`, and a hook process that spawns a detached helper and exits.
- `summarize.mjs`: p50, p95 and max per case.
- `procs.sh`: RSS, private memory (`smaps_rollup`) and CPU of every process whose environment holds the probe's `HOME`. From `slim.sh` on it adds waited-for children's CPU (fields 14 to 17 of `/proc/<pid>/stat`); `mem-*.log` count only each process's own CPU (fields 14 and 15).
- `mem.sh`: a daemon on a shallow clone of this repository at `d57b32d0f`, every test group at `manual`, oxlint at `edit`, complexity on, a fresh store. Variant `today`: the full `node_modules`. Variant `norunner`: a `node_modules` that holds only oxlint, so no runner host can start and no test closure is loaded.
- `restart.sh`: the `norunner` daemon with `daemon.unusedExitMinutes` 0.5, meant to time restarts at the next hook. The daemon did not stop within 20 min of its first pass, so the run was stopped there (`restart-norunner.log`).
- `slim.sh`: the `norunner` daemon after its first pass settles: idle CPU over 60 s, then 5 edits 15 s apart with hook latency and CPU per edit.

Outputs: `drive.jsonl`, `drive-summary.txt`, `drive-extra.jsonl`, `drive-extra-summary.txt`, `mem-today.log`, `mem-norunner.log`, `slim-norunner.log`, `restart-norunner.log`.
